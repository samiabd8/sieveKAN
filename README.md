# SieveKAN

Replication code for *Kolmogorov-Arnold Sieve Networks for High-Dimensional Estimation and Inference* (Abdurahman, 2026). The maintained package is [`KASN`](https://github.com/samiabd8/kasn) (`pip install kasn`).

| File | Contents |
|---|---|
| `KASN.py` | Core KASN classes |
| `KASN_nonpar_regression_script.py` | Nonparametric regression Monte Carlo (Tables 1-4), self-contained, SLURM-ready |
| `NLO-DML.py` | NLO-DML Monte Carlo for the partially linear model |
| `KASN_Abdurahman_CESG2026.pdf` | CESG 2026 version |
| `old_scripts/` | Earlier versions |
